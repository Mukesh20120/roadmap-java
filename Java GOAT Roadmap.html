2‑minute recall before you start

Explain each of these out loud without looking. If you can't, re-read your notes for it.

    1. Open "Today" and do the tasks in order. The queue always shows the next unfinished tasks, so there is nothing to decide.
    2. Minimum 1 per day keeps the streak alive. Your daily target (1–6) sets how many show up. After 6 the page stops you for the day.
    3. Every task produces something: a class, a test, a note, or a commit. Keep one GitHub repo, java-goat-journey, with a folder per phase, and commit after each task.
    4. Already know a topic? Press "Skip" to mark it known. Skipped tasks don't count toward the daily limit.
    5. Recall box: it picks tasks you finished about 3 and 7 days ago. Two minutes of saying them out loud is what makes the material stick.
    6. "Teach it" tasks close each phase: a short Medium draft or video outline. You already write and teach, so use that to lock it in.
    7. Sources: the official docs (dev.java, docs.spring.io, spring.io/guides) plus the JDK source in IntelliJ (Ctrl/Cmd+click into HashMap, ArrayList). Versions targeted: Java 25 LTS, Spring Boot 4.x, Spring Framework 7.
